---

### **Easy**

1. **Square of Numbers**

   - Write a function that takes an array of numbers and returns a new array with the square of each number using the `map` method.  
     Example: `[1, 2, 3, 4] → [1, 4, 9, 16]`

2. **Filter Even Numbers**

   - Write a function that takes an array of numbers and returns a new array containing only the even numbers using the `filter` method.  
     Example: `[1, 2, 3, 4, 5, 6] → [2, 4, 6]`

3. **Convert to Uppercase**

   - Write a function that takes an array of strings and returns a new array with all strings converted to uppercase using the `map` method.  
     Example: `['apple', 'banana'] → ['APPLE', 'BANANA']`

4. **Remove Short Words**

   - Write a function that filters out words with less than 4 characters from an array of strings using the `filter` method.  
     Example: `['cat', 'elephant', 'dog', 'fish'] → ['elephant', 'fish']`

5. **Add 5 to Each Number**
   - Write a function that adds 5 to each number in an array using the `map` method.  
     Example: `[10, 15, 20] → [15, 20, 25]`

### **Intermediate**

1. **Filter Prime Numbers**

   - Write a function that filters out all non-prime numbers from an array using the `filter` method.  
     Example: `[1, 2, 3, 4, 5, 6, 7, 8] → [2, 3, 5, 7]`

2. **Extract User Names**

   - Given an array of user objects, use `map` to create a new array containing only the names.  
     Example:  
     Input: `[{name: 'Alice', age: 25}, {name: 'Bob', age: 30}]`  
     Output: `['Alice', 'Bob']`

3. **Filter Adults**

   - Write a function that filters out all users under 18 years old from an array of objects using the `filter` method.  
     Example:  
     Input: `[{name: 'John', age: 17}, {name: 'Jane', age: 22}]`  
     Output: `[{name: 'Jane', age: 22}]`

4. **Double the Values of Specific Numbers**

   - Write a function that doubles all numbers greater than 10 in an array using `map` and leaves others unchanged.  
     Example: `[5, 12, 8, 20] → [5, 24, 8, 40]`

5. **Words Starting with a Specific Letter**

   - Write a function that filters out all words that don’t start with a specific letter.  
     Example: `['apple', 'banana', 'cherry', 'apricot'], 'a' → ['apple', 'apricot']`

6. **Multiply and Filter**

   - Write a function that multiplies all elements in an array by 3 and then filters out numbers greater than 15.  
     Example: `[2, 5, 8, 12] → [6, 15]`

7. **Filter Odd Length Strings**

   - Write a function that filters out strings with odd lengths from an array using the `filter` method.  
     Example: `['one', 'two', 'three', 'four'] → ['four']`

8. **Transform to Key-Value Pairs**

   - Write a function that maps an array of strings into an array of objects with each string as a `key` and its length as the `value`.  
     Example: `['apple', 'banana'] → [{key: 'apple', value: 5}, {key: 'banana', value: 6}]`

9. **Filter Specific Numbers**

   - Write a function that filters out all numbers except those divisible by both 2 and 3 from an array using `filter`.  
     Example: `[6, 9, 12, 18, 20] → [6, 12, 18]`

10. **Increment Array Elements**

    - Write a function that increments each number in an array by 1 and filters out numbers greater than 10.  
      Example: `[8, 9, 10, 11] → [9, 10]`

11. **Shorten Strings**

    - Write a function that maps an array of strings to return their first three characters only.  
      Example: `['hello', 'world', 'code'] → ['hel', 'wor', 'cod']`

12. **Custom Range Filter**

    - Write a function that filters out all numbers outside a given range from an array using `filter`.  
      Example: `[3, 8, 15, 22], range(5, 20) → [8, 15]`

13. **Object Value Transformation**
    - Given an array of objects, use `map` to increment the value of a specific property by 10.  
      Example:  
      Input: `[{item: 'A', count: 2}, {item: 'B', count: 5}]`  
      Output: `[{item: 'A', count: 12}, {item: 'B', count: 15}]`
